# Taskban

Бессерверный PWA-планировщик с канбан-досками поверх **Google Таблиц** и **Google Задач (Google Tasks)** с отображением в **Google Календаре**.

- **Приложение:** `https://sprinter11.github.io/taskban/`
- **Инструкция по настройке Google Client ID:** `https://sprinter11.github.io/taskban/setup.html`

## Возможности
- **Адаптивный интерфейс (Mobile + Desktop):** вкладки переключения колонок и свайп на смартфонах, нижние модальные окна, полноценная доска с drag-and-drop на десктопе.
- **Постоянная привязка по инвайт-ссылке:** параметры `client_id`, `sheet` и `board` сохраняются навсегда в `localStorage` после первого перехода — при последующем запуске с иконки PWA переходить по ссылке заново не нужно.
- **Кастомный календарный Date Picker:** быстрые кнопки (*Сегодня*, *Завтра*, *Суббота*, *+7 дней*) и сетка выбора даты.
- **Умная двусторонняя синхронизация с Google Tasks и Календарём:** импорт только новых активных задач (без засорения старой историей выполненных), пакетная запись в Google Sheets, автоматическая синхронизация при возврате на вкладку.
