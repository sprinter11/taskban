Подключение своего Google Cloud (бесплатно)

Taskban работает полностью в браузере без собственного сервера. Чтобы синхронизировать доски через Google Таблицы и Google Задачи, создайте свой бесплатный OAuth Client ID (занимает 3 минуты).

Если вас пригласили по ссылке: создавать свой проект не нужно. Просто откройте присланную ссылку — Client ID подставится автоматически.
  1. Создайте проект: откройте Google Cloud Console, введите любое название (например, Taskban) и нажмите Create.
  2. Включите два API: перейдите в APIs & Services → Library, найдите и нажмите Enable для:
    • Google Tasks API
    • Google Sheets API
  3. Настройте экран согласия (OAuth consent screen):
    • Выберите тип External → Create.
    • Заполните название приложения и ваш email в полях поддержки и разработчика.
    • На шаге Scopes добавьте: .../auth/tasks, .../auth/drive.file и email.
    • Важно: на вкладке OAuth consent screen нажмите кнопку Publish App (перевод в статус In Production). Иначе авторизация будет сбрасываться каждые 7 дней. Проходить верификацию Google не нужно (лимит до 100 пользователей).
  4. Создайте Client ID: перейдите в Credentials → Create Credentials → OAuth client ID, выберите тип Web application. В поле Authorized JavaScript origins вставьте строго этот адрес (без пути и без слэша на конце):
  5. Подключите в приложении: скопируйте сгенерированный Client ID (вида 123456-xxxx.apps.googleusercontent.com), вернитесь на доску, откройте Настройки Google и вставьте его.
